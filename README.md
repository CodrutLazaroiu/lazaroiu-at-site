# lazaroiu.at

Personal-professional website of Ioan-Codrut Lazaroiu — independent
energy-infrastructure and risk governance advisor, Vienna.

Static site built with [Astro](https://astro.build). Five locales
(EN default, DE, IT, AR, KO), no CMS, no client-side JavaScript,
no cookies, no tracking; all assets self-hosted.

## Develop

```
npm install
npm run dev
```

## Deploy

Pushes to `main` build and deploy to GitHub Pages via
`.github/workflows/deploy.yml`. Custom domain: `lazaroiu.at`.
